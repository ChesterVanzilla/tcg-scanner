# CardDex AI v6.13 – MasterSet

## Set-Projekte

- jedes bekannte Set kann mit einem Stern als persönliches Set-Projekt markiert werden
- neue Ansicht `Meine Set-Projekte`, auch für Sets, aus denen noch keine Karte vorhanden ist
- Projektstatus bleibt lokal auf dem Gerät gespeichert
- Set-Projekte werden in der JSON-Sicherung mitgesichert und beim Import wiederhergestellt
- Projektkennzeichnung in Set-Übersicht und Set-Details

## Fehlkarten und Wunschliste

- alle noch fehlenden Karten eines Sets können gesammelt zur Wunschliste hinzugefügt werden
- bereits vorgemerkte Karten werden nicht doppelt angelegt
- eine einzige Sammelaktion ersetzt viele einzelne Tippvorgänge
- Statusanzeige zeigt, wie viele Karten im Set fehlen und wie viele noch vorgemerkt werden können

## SetDex-Erweiterungen

- Projektansicht zeigt die noch fehlenden Karten über alle markierten Sets hinweg
- Projekt-Sets bleiben sichtbar, auch wenn noch keine Karte daraus in der Sammlung liegt
- bisherige Suche, Filter, Set-Fortschritt, Dubletten, Cardmarket und Einzel-Wunschlisten bleiben erhalten

## Datenübernahme

Bestehende Sammlungen, Wunschlisten, Bilder, Cardmarket-Links, Scannerhistorie und Set-Caches bleiben vollständig erhalten. Die neue Projektliste wird lokal gespeichert und benötigt keine zusätzliche Anmeldung.
